# Phase 14 — Content Pass (Blog + CFPs)

**Arc:** C — Credibility & Reach

## Goal
Turn the benchmark + results + leaderboard into talk submissions and a blog post, using the existing CFP tracker and target list already maintained in the private strategy repo.

## Why It Matters
A reproducible benchmark with a live leaderboard is a much stronger conference pitch than a single incident report — this phase is where the project starts paying back into the existing career/conference strategy.

## Deliverables
- Blog post: the story (two incidents → generalized taxonomy → public benchmark → early results), written in the established personal voice/style already used for other public writing in this workflow.
- CFP submissions to relevant venues from the existing tracker (DEF CON AI Village, OASec, and others already tracked) using the benchmark as the talk's spine.
- Cross-link the blog post, the leaderboard site, and (once available) the paper — each should drive traffic to the others.

## Acceptance Criteria
- Blog post published and linked from the repo README.
- At least one CFP submitted referencing the live leaderboard URL as evidence, not just a promise of future work.

## Dependencies
Phase 11 (leaderboard), Phase 13 (paper draft, even if not yet accepted, strengthens CFP submissions).

## Risks / Notes
No JPMC references anywhere in this content, per existing standing rule — this is independent research tooling, keep it that way explicitly in any bio/attribution text.
